# ArcGIS Pro — How to Use

A tab-by-tab guide to ArcGIS Pro, organized the way the software is: the Project backstage,
the core ribbon tabs, the contextual tabs, and the panes. The second half covers wildfire
simulation workflows for both the United States and Canada.

Written for researchers and students who have ArcGIS Pro open on a second monitor and want
to know what a button does and when to use it.

!!! note "Version"
    Every page on this site assumes **ArcGIS Pro 3.7** (released May 2026). Where a feature
    arrived in a specific release, the page says so. If your ribbon looks different, check
    your version first — *Project → About*.

## Wildfire simulation

- [Wildfire overview](wildfire/index.md) — what this half of the site covers.
- [Fuel models — US vs Canada](wildfire/concepts/fuel-models.md) — start here if you are
  choosing an ecosystem to work in.
- [Simulators — overview and how to choose](wildfire/simulators/index.md).

!!! warning "US and Canadian fire models are not interchangeable"
    Scott & Burgan / Anderson fuel models and the Canadian FBP System fuel types are
    different classifications feeding different fire behaviour equations. Mixing them
    produces output that looks plausible and is wrong. Every workflow page on this site
    separates the two explicitly.
